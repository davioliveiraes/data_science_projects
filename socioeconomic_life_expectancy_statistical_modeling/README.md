# Modelagem Estatística em Indicadores Socioeconômicos

## 📊 Descrição do Projeto

Este projeto aplica técnicas de modelagem estatística para analisar a relação entre indicadores socioeconômicos e expectativa de vida. O objetivo é identificar quais fatores socioeconômicos têm maior impacto na expectativa de vida da população, utilizando métodos estatísticos avançados para construir modelos preditivos robustos.

## 🎯 Objetivos

- Analisar a correlação entre diferentes indicadores socioeconômicos e expectativa de vida
- Aplicar técnicas de modelagem estatística para identificar padrões nos dados
- Construir modelos preditivos para estimar expectativa de vida com base em fatores socioeconômicos
- Realizar análises exploratórias para extrair insights dos dados

## 🛠️ Tecnologias Utilizadas

- **Python** - Linguagem principal do projeto
- **Pandas** - Manipulação e análise de dados
- **NumPy** - Operações numéricas e arrays
- **Seaborn** - Visualização estatística de dados
- **Matplotlib** - Criação de gráficos e visualizações
- **Statsmodels** - Modelos estatísticos e testes
- **Scikit-learn** - Preprocessamento de dados (StandardScaler)

## 🚀 Como Executar

### Pré-requisitos

- Python 3.7 ou superior
- Jupyter Notebook ou JupyterLab

### Instalação das Dependências

1. Clone o repositório:
```bash
git clone https://github.com/davioliveiraes/data_science_projects.git
cd data_science_projects/socioeconomic_life_expectancy_statistical_modeling
```

2. Instale as bibliotecas necessárias:
```bash
pip install pandas numpy seaborn matplotlib statsmodels scikit-learn jupyter
```

### Execução

1. Inicie o Jupyter Notebook:
```bash
jupyter notebook
```

2. Abra o arquivo `socioeconomic_life_expectancy_statistical_modeling.ipynb`

3. Execute as células sequencialmente para reproduzir a análise

## 📈 Metodologia

O projeto segue uma abordagem estruturada de análise de dados:

1. **Exploração dos Dados** - Análise inicial dos dados e identificação de padrões
2. **Preprocessamento** - Limpeza e preparação dos dados para modelagem
3. **Análise Estatística** - Aplicação de testes estatísticos e análise de correlações
4. **Modelagem** - Construção de modelos estatísticos usando OLS (Ordinary Least Squares)
5. **Validação** - Avaliação da performance dos modelos construídos
