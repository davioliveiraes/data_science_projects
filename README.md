# 📊 Projetos de Ciência de Dados

Repositório destinado a aplicações e exercícios desenvolvidos com ferramentas de Python para **Machine Learning** e **Inteligência Artificial**, voltados para **Ciência de Dados**.

## 🎯 Sobre o Repositório

Este repositório contém uma coleção de projetos práticos e exercícios que demonstram a aplicação de técnicas de ciência de dados em diferentes domínios e problemas reais. Cada projeto é desenvolvido com foco em boas práticas de programação, análise exploratória de dados e implementação de algoritmos de machine learning.

## 🛠️ Tecnologias Utilizadas

- **Python** - Linguagem principal
- **Pandas** - Manipulação e análise de dados
- **NumPy** - Computação numérica
- **Matplotlib/Seaborn** - Visualização de dados
- **Scikit-learn** - Machine Learning
- **Jupyter Notebooks** - Desenvolvimento interativo
- **TensorFlow/Keras** - Deep Learning
- **Plotly** - Visualizações interativas

### 📈 Análise Exploratória de Dados
Projetos focados em técnicas de EDA, visualização de dados e insights estatísticos.

### 🤖 Machine Learning
Implementação de algoritmos de aprendizado supervisionado e não supervisionado para diferentes tipos de problemas.

### 🧠 Deep Learning
Projetos utilizando redes neurais para tarefas como classificação de imagens, processamento de linguagem natural e previsão de séries temporais.

### 📊 Análise Preditiva
Modelos de previsão e forecasting aplicados a dados reais.

## 🎓 Exercícios e Estudos

Além dos projetos principais, o repositório contém exercícios práticos organizados por área de conhecimento:

- **Estatística Descritiva**
- **Pré-processamento de Dados**
- **Feature Engineering**
- **Validação de Modelos**
- **Otimização de Hiperparâmetros**

## 🎯 Objetivos de Aprendizado

- Aplicar técnicas de análise exploratória de dados
- Implementar algoritmos de machine learning
- Desenvolver pipelines de dados eficientes
- Criar visualizações informativas e insights acionáveis
- Praticar boas práticas de desenvolvimento em ciência de dados
